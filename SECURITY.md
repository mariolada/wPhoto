# Security and privacy reports

Please open a GitHub issue with a concise, sanitised description of the problem.
Never upload personal photos or videos, an Apple ID, device identifiers, complete
diagnostic logs or private Windows paths.

For a security issue that should not be public, use GitHub's private vulnerability
reporting option when it is available on this repository. Include the affected
wPhoto version, Windows version and reproducible steps, but replace personal names
and paths with neutral examples.

wPhoto does not use a cloud service, user accounts or telemetry. Import history
and diagnostic logs remain on the Windows computer running the application.
